# Yoga Lovers Club Telegram Bot

Python 3.11+ / aiogram 3 / aiohttp / SQLite / YooKassa API.

## Что уже реализовано

- `/start` → выбор из двух продуктов.
- Ветка «ЭНЕРГОКОМПЛЕКС».
- Ветка «ИНДИВИДУАЛЬНЫЕ ЗАНЯТИЯ».
- Переходы внутри каждой ветки редактируют одно и то же сообщение.
- Постоянная нижняя клавиатура:
  - 👤 Обо мне
  - 💬 Поддержка
  - 🎁 Пробная тренировка
- Email обязателен ДО создания платежа.
- Платёж создаётся сервером с актуальной ценой из кода, а не из данных клиента.
- После оплаты webhook перепроверяется через API YooKassa.
- Повторный webhook не создаёт повторную продажу.
- После оплаты:
  - покупателю отправляется доступ / подтверждение;
  - администратору и в группу приходит уведомление;
  - есть крупное напоминание сформировать чек в «Мой налог».
- `/buyers` — CSV-таблица всех успешных оплат, только для администратора.
- `/stats` — количество и сумма успешных оплат.
- Секреты находятся в `.env`.
- Базовый rate limit от спама.
- Ограничение размера webhook-запроса.
- Секретный webhook path.

## 1. Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env .env
```

Заполните `.env`.

## 2. Сгенерировать секрет webhook

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Вставьте результат в `WEBHOOK_SECRET`.

## 3. Запуск

```bash
python bot.py
```

В логах появится строка:

```text
YooKassa webhook URL: https://ВАШ-ДОМЕН/yookassa/СЕКРЕТ
```

Именно этот URL нужно указать в личном кабинете YooKassa:
**Интеграция → HTTP-уведомления**.

Включите событие:
- `payment.succeeded`

YooKassa требует публичный HTTPS URL.

## 4. Что заменить перед запуском в прод

В `.env` обязательно задайте реальные:

- `BOT_TOKEN`
- `YOOKASSA_SHOP_ID`
- `YOOKASSA_SECRET_KEY`
- `PUBLIC_BASE_URL`
- `WEBHOOK_SECRET`
- `YANDEX_DISK_URL`
- `TERMS_URL`
- `PRIVACY_URL`
- `OFFER_URL`

Не публикуйте `.env` в GitHub.

## 5. Важный юридический момент для самозанятой

Этот проект не может сам по себе гарантировать «соответствие всем законам РФ».
Юридическое соответствие зависит от вашего статуса, текста оферты, обработки
персональных данных, фактического оказания услуг, налогового режима и настроек
платёжного сервиса.

Для самозанятого чек по полученному доходу обычно формируется через приложение
«Мой налог». Поэтому бот специально уведомляет администратора после каждой
успешной оплаты и сохраняет email покупателя.

Не включайте объект `receipt` для кассового чека в код просто «на всякий случай»:
для разных статусов продавца схема фискализации различается.

## 6. Защита

Бот не доверяет содержимому webhook. После `payment.succeeded` он делает
серверный GET-запрос в YooKassa и дополнительно проверяет:

- статус `succeeded`;
- `paid=true`;
- сумму;
- валюту;
- Telegram ID в metadata;
- код продукта в metadata.

Это принципиальнее, чем просто принимать любой POST на webhook.

Полноценную защиту от сетевого DDoS должен обеспечивать хостинг/reverse proxy
(Cloudflare, nginx rate-limit, firewall и т.п.). Python-бот не способен
самостоятельно остановить volumetric DDoS до того, как трафик дошёл до сервера.

## 7. Команды администратора

```text
/buyers
/stats
```

Админ по умолчанию: `270422682`.
Группа: `-5507039744`.

Убедитесь, что бот добавлен в админ-группу и может отправлять туда сообщения.

## 8. Проверка перед реальными продажами

1. Используйте тестовый магазин YooKassa.
2. Сделайте тестовую оплату.
3. Проверьте уведомление пользователю.
4. Проверьте сообщение в личку админу.
5. Проверьте сообщение в админ-группе.
6. Проверьте `/buyers`.
7. Только затем переключайте `SHOP_ID` и `SECRET_KEY` на боевые.
